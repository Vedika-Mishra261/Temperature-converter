# 🌡️ Temperature Converter

A simple and responsive Temperature Converter web application built using **HTML, CSS, and JavaScript** as part of my Web Development Internship at **Veda Technology**.

The application allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin with accurate results and a clean, user-friendly interface.

## 📐 Conversion Formulas

**Celsius to Fahrenheit**

```javascript
fahrenheit = (celsius * 9/5) + 32;
```

**Fahrenheit to Celsius**

```javascript
celsius = (fahrenheit - 32) * 5/9;
```

**Celsius to Kelvin**

```javascript
kelvin = celsius + 273.15;
```

**Kelvin to Celsius**

```javascript
celsius = kelvin - 273.15;
```
